| 2026-10-13 | When asking for pale day greens, the main Claude session told the art agent the greens would turn **pale pink** in the strobe's colour inversion | Inverting a colour flips its brightness too (255 − value), so a pale green becomes a **dark** plum, not a pale pink. | 2026-10-13 | While designing the click that sends staff to a sleeper (M3), the AI's first idea was to call `Attender.Attend(p, location)` directly from the game's click handler on the `[]Attender` from `Hospital.Staff()` | `Attend` reads `p.State()` with no lock while the patient's goroutine can be changing it, so that is a data race, and it would also skip the hospital's own round-robin and episode history. Caught on paper before any code was written | The click calls `Hospital.RegisterEpisode` (through `Ward.Attend`), which holds the hospital's mutex; the simulation got a `ManualAttend` option so the goroutine only announces the sleep and does not attend by itself |

| 2026-10-13 | The page-flip progress was advanced with `progress += 1.0/14` per tick and compared with `==` to the target | Fourteen additions of 1/14 do not give exactly 1 in floating point, so the flip never finished and the next `TurnPage` failed with "still moving" (the test caught it) | The comparison uses a tiny tolerance and then sets the progress to exactly the target |
| 2026-10-13 | The AI chained `go test ... \| tail && git commit`, so the Severe-patients commit went in with one failing test | The pipe's exit status is `tail`'s, not the test's; and the quick-answer bonus had legitimately changed the score the old dispatch test expected | The test now expects the bonus, and the commit was amended; checks are read before committing |
| 2026-10-13 | The art agent's field rect for the wristband WARD value, (51,34), left no gap after the label already printed on the band, so the ward read "WARDB" at 1x (the AI built it exactly to that rect) | A field rect taken from the art notes was used without looking at the label next to it | The value now starts at x 55, so it reads "WARD B" |
