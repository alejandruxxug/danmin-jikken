## 🧑‍🏫 OOP in Go: how each concept shows up in the game

Go has **no classes and no inheritance**. "OOP in Go" means structs, methods, interfaces and embedding. Every concept below should be something Alejo can point at in the demo.

| OOP concept | Go mechanism | In Danmin Jikken |
|---|---|---|
| **Encapsulation** | Unexported fields + methods, `NewX()` constructors | `Patient` hides its sleep state; only `Nudge()` and `IsAsleep()` touch it |
| **Abstraction** | Interfaces | `Scene` (`Update`, `Draw`), `Document` (`Check(rules) []Discrepancy`) |
| **Polymorphism** | Interface values | The desk handles SettlerID, Referral, SleepLog and Wristband through one `Document` list |
| **Composition over inheritance** | Struct embedding | A `Patient` embeds `Sleeper` and `Person`. The trial patients embed a different `Sleeper` (the twist is literally a different type) |
| **Interface segregation** | Small interfaces | `Sleeper` is just `Sleep()` / `Wake()` / `Asleep() bool` |

## 💤 The sleepy patients = goroutines

Each patient runs a goroutine with a random sleep timer:

```go
// sketch, not final
func (s *narcolepticSleeper) run(ctx context.Context, events chan<- SleepEvent) {
    for {
        select {
        case <-ctx.Done():
            return
        case <-time.After(s.nextAttack()): // random interval
            events <- SleepEvent{ID: s.id, Asleep: true, At: s.clock.Now()}
        }
    }
}
```

**Rule that matters:** Ebitengine's `Update`/`Draw` run on one thread. **Goroutines never touch game state directly.** They send events on a channel, and the `Ward` drains the channel inside `Update`. That avoids data races and is a good line for the sustentación.

- `context.Context` stops a patient's goroutine when they're discharged or the scene ends.
- The **game clock** is injected, so the 3:17 AM in-game time is controllable (and testable).
- The **ward monitor** (night) draws one line per live goroutine. That's the debug view and a story beat at once.

## 🤖 Agent backdoor (test mode)

Alejo, 2026-10-13: the game has a **backdoor so a Claude agent can go exactly where it needs to** and testing is easy. It's a set of command-line flags, **off unless `-agent` is passed**. Same idea as a cheat menu. All of it lives in **one file, `game/agent.go`**, in plain Go (Alejo has to defend it), and it only calls things the game already has (SceneManager, Ward, clock). It never touches `hospital/`.

```bash
cd game
go run ./cmd/danmin -agent -scene day.reception -day 2 -clock 15:40 -seed 7 \
    -input ../testdata/admit_two.txt -shot /tmp/out.png -dump /tmp/state.json -quit
```

| Flag | Does | Why the agent needs it |
|---|---|---|
| `-agent` | Turns test mode on. Without it every other flag below is ignored | Players can't trip it |
| `-scene <id>` | Starts straight in that scene (ids in the table below) | No playing from the title to reach day 3 |
| `-day N`, `-clock HH:MM` | Sets the day and in-game time (the clock is injected already) | Day 3 / 3:17 AM on demand |
| `-seed N` | Fixes the random seed: same patients, same order, every run | Screenshots are comparable between runs |
| `-flags a,b` | Pre-sets story flags (choices carried day → night) | Test any night branch directly |
| `-speed N` | Game time ×N | Watch a whole shift in seconds |
| `-input <file>` | Plays a script of inputs (below) | Clicks and keys without a human |
| `-shot <file.png>` | Saves a screenshot at **1× (480×270)**, plus `-shot4` at ×4 to compare with the Figma view | The agent *sees* the screen |
| `-dump <file.json>` | Writes the game state: scene, day, clock, patients (state, room), rooms, scores, flags | Check logic, not only pixels |
| `-pan X` | Camera x at the start, 0–240 (default 120 = the Figma frame's crop). Reception only | Shots line up with the Figma view, or show the far ends of the room |
| `-nocrt` | Turns the day CRT filter off (Art Direction → Day screen). **Works without `-agent` too** (a player option; **F10** toggles it in the game). With the filter on, `-shot4` and `shot4` are the filtered picture; `-shot` (1×) is always the plain canvas | Screenshots line up pixel for pixel with the Figma views |
| `-line N` | Night scenes: start at the first command on or after line N of the script file (it plays the story up to there silently; a menu on the way is answered with the option your `-flags` already chose, else the first) | Jump into the middle of a night |
| `-poweron` | Starts the day with the CRT turn-on playing (48 ticks: dot, line, open with a white flash, settle). See it with `wait N` and `shot4`; with `-nocrt` it is a plain fade from black | Check the day turning on like a CRT |
| `-reduce-flashing` | Replaces the strobe with one slow invert-and-fade (Settings → Reduce flashing). **Works without `-agent`** | Check the safe version |
| `-scores <file>` | Scores file to read and write. Without it the top-10 keeps scores in memory (the real `danmin_scores.txt` is never touched in test mode) | Top-10 and the ghost row on a scratch file |
| `-score N` | Today's score at the start; `day.top10` saves it as a row | Reach the top-10 and "NEW RECORD" directly |
| `-sleepy` | Admitted patients nod off within a second and sleep ~2 minutes | Reach sleepers, the hallway and the no-room alert fast |
| `-fullscreen` | Starts in fullscreen. **Works without `-agent`** (it is a normal player option; F11, Alt+Enter and Cmd+F toggle it too; the window opens at the biggest whole-number scale that fits 90% of the screen and can be resized, `key F11` in a script does the same). Screenshots are always of the 480x270 canvas, so this never changes them | A player option, not a test one |
| `-dark N` | Draws **every** guest N palette steps darker (0-3), to judge the Severe darkening without waiting for a Severe patient to wake up (`dark N` does the same inside a script). In the dump: `forceDark` | The darkening is otherwise hidden: a Severe patient in a bed is not drawn |
| `-quit` | Exits after the input script ends (or after `-frames N`) | Runs inside a test command |

**Who attends a sleeper (M3):** a patient only enters the hospital when the player stamps ADMIT, and then gets a goroutine (`simulation.Run` with `ManualAttend`). The goroutine only announces "fell asleep" / "woke up"; the player's click calls `Hospital.RegisterEpisode`, so the next attender in line (round robin) attends and a room is assigned if one is free. `AssignRoom` then tells the game which room, or `ErrNoRoomAvailable` (checked with `errors.Is`), which opens the no-room alert and lays the patient in the hallway. A patient nobody attends just wakes up on their own.

**Shooting mid-tilt:** a script command that changes the scene ends its frame, so `desk` then `wait 2` then `shot4` lands about 3 frames into the 18-frame tilt (`wait 7` is about halfway); `wait 20` shows the settled desk. The same works for `reception` (tilting back up).

**Scores without `-scores`:** the top-10 keeps the rows in memory for the run (`Env.MemScores`) and shows `KEPT IN MEMORY`; the real `danmin_scores.txt` is never touched in test mode.

Notes on the backdoor as built: `-shot`, `-shot4` and `-dump` are written when the run ends (after `-frames N`, or when the `-input` script ends, or after one frame if neither is given); `shot`/`dump` lines inside a script write mid-run. Without `-quit` the window stays open after the run ends. `-speed N` multiplies both the clock and the patients' timers. `-seed 0` means a random seed.

## 🌙 Night script format (M5)

One plain text file per night in `game/night/scripts/` (embedded with `go:embed`), one command per line; `#` starts a comment. The parser is `night/script.go`, every error names the file and line (`night1.txt line 12: unknown expression ...`). The engine (`night/engine.go`) knows nothing about drawing, so tests run it without a window; `night/draw.go` paints it; `game/night_scene.go` is the glue.

| Line | Does |
|---|---|
| `Mayu (smile): words` | A line. The word in brackets is the expression (`night/faces.go`: Mayu `smile bright laugh happy soft blank pout`, Hana `tired flat soft`). More parts can follow: `Mayu (smile eyes=half arms=clasp): ...` (keys `eyes brows mouth fx arml armr arms`, values are the layer names). A speaker with no sprites (`Note: ...`) gets the name plate only |
| `~ words` | Your thought: light grey, no name plate |
| `choice` + `option Text \| set flag \| jump label` | A menu of 2 to 3 options. Hover with the mouse or Up/Down; click or Enter/Space picks |
| `label x`, `jump x`, `if flag jump x`, `ifnot flag jump x`, `set flag` | Branches and flags |
| `bg station / ceiling / black / white / <other>` | Backdoor-reachable backgrounds. Any other name draws a black screen with `PLACEHOLDER: <NAME>` (the batch 2 art that does not exist yet) |
| `prop can` (`coffee can syringe note monitor`, `prop clear`) | Things on the counter; `monitor` draws the ward traces in the monitor rect |
| `show mayu`, `hide`, `faces` | One girl at (112, 2), or the Prologue's two upside-down faces |
| `fx fade_in / eyes_close / red_pixel / flat_line / line_back / seventh` | Screen effects |
| `speed N`, `wait S`, `sfx x`, `music x`, `end day2` | Typewriter letters per second; a pause (a click skips it); sound cues (logged only, sound is M7); the end: `dayN` is the day that follows |

**Flags** (`night.Flags`, one map on `Env.Flags`): choices write into it, the day will read it (M4's day 2 and 3 memo rules still need that wiring). The dump lists them. The name plate is written in the speaker's handwriting (`night/handwriting.go`: Hana joins, Mayu's seeded joins and ±1 px jitter; reusable for the notes), other speakers use Silkscreen.

**The CRT** (`game/crt.kage`, `crt.go`): one Kage shader on the finished picture, day scenes only (`usesCRT`), seven uniforms (`Scanline Vignette Curve Day Invert Time Filmed`). The strobe scene sets `Env.Invert` and the shader swaps black and white.
